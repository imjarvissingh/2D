# Stage 1 · Recon

Target category: tablet-first hand-drawn animation studios (the "Procreate Dreams" class of app).
Note: the `replica-skill` framework was not reachable from this session, so this stage was carried out by hand following the same intent: map features, UI flow and pain points. No code, assets or copy from any existing product were used.

## Core feature map (category norms)

| Area | What users expect |
|---|---|
| Drawing | Pressure-sensitive brushes, eraser, fill, colour picker, adjustable size/opacity |
| Timeline | Frame-by-frame cels, multiple tracks/layers, duplicate/insert/delete frames |
| Onion skin | See previous/next frames tinted while drawing |
| Playback | Loop playback, adjustable FPS, scrub |
| Projects | Gallery of projects, autosave, rename, delete |
| Export | Animated GIF, video, image sequence / sprite sheet |
| Input | Stylus + touch + keyboard shortcuts on desktop |

## Typical UI flow

1. Gallery → create project (pick canvas size)
2. Studio: canvas centre, tools on the side, timeline along the bottom
3. Draw frame → add/duplicate frame → onion skin guides the next drawing
4. Play back, adjust timing
5. Export and share

## User pain points

- **Platform lock-in**: the category leaders run on one tablet OS only; nothing on the web, nothing on a laptop.
- **Paid up front** with no way to try the workflow first.
- **Feature bloat**: performance mode, 3D-ish transforms, audio mixing and keyframe curves crowd the UI for people who just want to flip a few drawings.
- **Steep timeline**: track/keyframe hybrids confuse beginners who think in "frames".
- **Heavy files**, slow export of short loops.
- **No account-free portability**: project files tied to one app.
