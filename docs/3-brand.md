# Stage 3 · Brand

## Name
**Loomframe** — weaving drawings into motion, one frame at a time. Original coined compound; no reference to any existing product name or mark.

## Tagline
"Draw it. Flip it. Loop it."

## Voice
Warm, short, encouraging. Talks like a sketchbook, not a software manual.
- Empty gallery: "Your shelf is empty. Start a loop."
- Saved toast: "Saved to this device."
- Export toast: "Your loop is ready."

Onion skin: previous frame in Ember, next frame in Lagoon.

## Logo
Three offset rounded rectangles (stacked frames) with a single curved stroke running through them, drawn in inline SVG. Created for this project.

## Type
System UI stack (no font licensing): `ui-rounded, "SF Pro Rounded", system-ui, sans-serif`.
